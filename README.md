Windows Failed-Login Investigation

Project Overview

This project demonstrates a simulated Security Operations Center (SOC) investigation into repeated Windows authentication failures.

Objective

- Analyse Windows failed-login events.
- Identify patterns that may indicate brute-force activity.
- Establish a timeline of suspicious authentication attempts.
- Document findings and recommend appropriate response actions.

Data Source

Synthetic Windows Security event data created for educational purposes.

Windows Event ID: 4625 — An account failed to log on.

Tools and Techniques

- Windows Security event analysis
- Authentication log investigation
- Failed-login pattern detection
- Incident triage and documentation
- MITRE ATT&CK mapping

Investigation Status

Initial project setup. Sample logs, detection logic, analysis and findings will be added as the investigation progresses.

Disclaimer

This is an educational project using simulated data. No real user accounts or production systems are involved.
